# 历史文档归档

此目录保存 2026 年 9 月量化平台整理、跨服务器迁移和 H200 上线过程的原始记录。

这些文件用于审计和追溯，不是当前操作手册。它们可能包含已经完成的 TODO、旧 NAS 路径、旧权限状态、旧服务器路径或迁移期命令。

当前事实以以下文件为准：

1. `../../AGENTS.md`
2. `../agent/CONTEXT.md`
3. `../agent/RUNBOOK.md`
4. `../HANDOFF.md`

归档内容的主要用途：

- `migration.md`：平台从脚本整理成 Web/API/Runner 的过程。
- `server-migration.md`：通用跨服务器迁移计划。
- `h200-migration.md`：迁移到 H200 的执行记录。
- `network.md`：网络问题排查和 Astrill 路由背景。
- `h200-device.md`：早期 H200 设备快照。
- `AGENT_CONTEXT-legacy.md`、`H200_RECOVERY-legacy.md`：旧入口文档。
