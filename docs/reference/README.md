# 按需参考资料

这些资料不需要在日常使用前全部阅读：

- `RECOVERY.md`：H200 重启、系统重装、项目或镜像丢失后的恢复。
- `PERFORMANCE.md`：可复用的性能测试方法和验收规则；当前数字见 `../status/CURRENT.md`。
- [LAYER_TRACE_EXPORT.md](LAYER_TRACE_EXPORT.md)：单图逐层软件参考导出、T32 布局与使用边界。
- `../evidence/`：按日期保存的性能、备份和恢复验收证据。
- `../../rebuild/REBUILD_GUIDE.md`：从 Docker 镜像、Conda 环境包或依赖清单重建。
